STEP 04 · UNDERSTAND THE SYSTEM

How the pieces connect

The same backend serves this plain HTML, CSS, and JavaScript page and the investigation API. The optional language model only paraphrases a numeric explanation; WNTR provides hydraulic values.

Why keep a catalog?

The 99 stored signatures cover Net1 fault types, locations, and three severities. Building them costs 100 offline runs including baseline. The live search uses them to avoid blindly simulating every pipe. It still verifies shortlisted strengths with new runs.

What does a low mismatch mean?

The simulated readings are close to the observed values after pressure and flow have been put on comparable scales. It does not prove the fault. Another cause may fit nearly as well, and unmodelled causes remain possible.

What does the agent decide?

The graph controls the investigation stages, chooses a shortlist, estimates severity, uses a simulation budget, checks ambiguity, and may suggest an unmeasured junction. The current v2 core is simulation retrieval and verification, not a calibrated Bayesian posterior.

What is still missing?

This is a synthetic Net1 demonstration with broad sensor coverage. Real deployment needs model calibration, demand changes, partial sensor tests, multiple faults, actual valve locations, and a durable job system. No physical action is automated.
